1. NLP TRANSFORMER ENCODER all-MiniLM-L6-v2

ArchiveMind utilizes a distilled BERT transformer architecture with 6 transformer layers, 384 hidden dimensions, and 12 multi-head self-attention mechanisms.

Attention(Q, K, V) = softmax( (Q · KT) / √dk ) · V

Self-attention transfer loss matches teacher-student relation matrices, preserving deep grammatical syntax and archaic vocabulary nuances while operating at <5ms inference latency.

2. UNIT HYPERSPHERE GEOMETRY (𝕊383) L2 NORMALIZED

All raw embedding vectors are strictly projected onto the surface of a 384-dimensional unit hypersphere via Euclidean L2 normalization:

v̂ = v / ||v||2 = v / √(∑i=1384 vi2)

Consequently, the Cosine Similarity simplifies to the exact inner dot product: cos(θ) = û · v̂ = ∑ ui vi. Angular distance is given by θ = arccos(cos(θ)).

3. SVD / PCA DIMENSIONALITY REDUCTION 384-D → 2-D

To render the 384-dimensional latent semantic space onto a human-interpretable 2D plane, we compute Singular Value Decomposition on the zero-centered embedding matrix X̃:

X̃ = U · Σ · VT  &implies;  Z2D = X̃ · V[:, :2]

The first two right-singular vectors V1 and V2 form the optimal orthogonal projection plane capturing maximum global variance (~42.8% cumulative variance ratio).

4. DUAL HYBRID FUSION THEOREMS BM25 + MINILM

ArchiveMind harmonizes lexical keyword inverted indices with continuous vector embeddings via two complementary fusion equations:

Slinear(d, q) = α · S̃BM25 + (1 - α) · S̃MiniLM
RRF(d) = ∑m ∈ {BM25, Vector} 1 / (60 + rm(d))

BM25 provides exact matching for specialized historical and Latin nomenclature, while MiniLM surfaces conceptually related folios lacking lexical overlap.
